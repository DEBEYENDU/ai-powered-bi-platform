AI-Powered Business Intelligence and Analytics Platform for enterprise data-driven decision making.

## 📋 Project Overview
Final Year BE Project - AI-powered BI platform with data integration, ETL, dashboards, predictive analytics, AI insights and natural language querying.

## 🛠 Tech Stack

* Frontend: React + TypeScript + Tailwind
* Backend: Python FastAPI + SQLAlchemy 2.x
* Database: PostgreSQL
* Cache: Redis
* ML/AI: scikit-learn, TensorFlow, LLM integration
* Infra: Docker, PostgreSQL, Redis
